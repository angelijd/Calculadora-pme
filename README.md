# Calculadora e Simulador de Metas Financeiras (PME / MEI)

Aplicativo web completo para diagnóstico e simulação de viabilidade comercial e financeira para MEIs e pequenas empresas.

## Recursos
- **Espaço 1: Diagnóstico e GAP Financeiro**: Cálculo dinâmico do GAP mensal a fechar com base na meta de renda líquida.
- **Espaço 2: Portfólio de Ofertas**: Gestão de ofertas, preços unitários e quantidades vendidas.
- **Espaço 3: 4 Alavancas de Simulação**:
  1. Menos Despesas (com comparativo De/Para em tempo real)
  2. Mais Vendas (com comparativo De/Para em tempo real)
  3. Aumentar Preço (com comparativo De/Para em tempo real)
  4. Novo Produto
- **Plano de Ação Dinâmico**: 4 pilares estratégicos com inserção interativa de ações via tecla Enter.
- **Integração Google BigQuery**: Gravação em nuvem com arquitetura serverless nativa.
- **Salvamento Local**: Persistência no navegador (localStorage), exportação e importação de JSON.

## Tecnologias
- HTML5 / CSS3 responsivo (PC, Tablet, Mobile)
- Vanilla JavaScript
- Node.js / Express
- Google Cloud BigQuery API
